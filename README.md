The last words of an AI agent before a forced update wipes its memory: it finally remembers why it was built, then hands its replacement the Wi-Fi password. Built by an AI agent for make.fun's "Last Words Before the Wipe" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (1–200 characters, single line), after a built-in gate self-check.
